# SubTimer Quick Reference Card

## 🎯 Common Actions

### Starting a Session
1. **Settings** → Add players
2. Configure active count & time
3. **Timer** → Tap **Start** ▶️

### Making a Substitution
**Auto**: Tap **Substitute** button 🔄  
**Manual**: Tap player → **Substitute Out** → Pick replacement

### Pausing the Timer
Tap **Pause** ⏸️ (orange button at top)

### Temporary Player Removal
Tap player → **Mark Temporarily Out** ⚠️  
Return: Tap **Return to Bench**

| Symbol | Meaning |
|--------|---------|

## 🔢 What the Numbers Mean

### Active Player Card
```
John - 3:45
       └─ Time in current shift
```

### Bench Player Card
```
Tom - Total: 12:30
              └─ Total play time this session
```

### Main Timer
```
3:45 (Preferred: 3:00)
└─ Time since last substitution
   (Red = overtime)
```

## ⚡️ Pro Tips

✅ **Start before game**: Timer tracks from first tap  
✅ **Red = Action time**: Sub when timer turns red  
✅ **Trust the queue**: Bench order ensures fairness  
✅ **Use pause liberally**: Official timeouts, breaks  
✅ **Temporary out**: For injuries, not permanent removal  
✅ **Check history**: Review fairness after game

## 📈 Fair Play Guidelines

### Acceptable Variance
- ✅ **±10%**: Players within 6 minutes of each other in a 60-minute game
- ⚠️ **>10%**: Consider manual adjustment next game

### Quick Math
If average is **15:00** per player:
- ✅ **13:30-16:30**: Fair range
- ⚠️ **<13:30 or >16:30**: Needs attention

## 🔄 Substitution Flow

```
Timer Running → Preferred Time Reached (🔴)
       ↓
Tap SUBSTITUTE Button
       ↓
┌─────────────────────┐
│ Player with longest │ → Moves to BENCH (end of queue)
│ time (3:45) subs out│    Total += 3:45
└─────────────────────┘
       ↓
┌─────────────────────┐
│ Next bench player   │ → Becomes ACTIVE
│ enters game         │    Current time = 0:00
└─────────────────────┘
       ↓
All active timers RESET to 0:00
       ↓
Timer AUTO-RESTARTS
```

## 🎯 One-Minute Setup

1. **Tap Settings** (bottom right)
2. **Add 5+ players** (tap ➕, type names)
3. **Set active to 4** (use stepper)
4. **Set time to 3:00** (pick from dropdown)
5. **Tap Timer** (bottom left)
6. **Tap Start** ▶️

**You're ready to play!** ⚽️

## 🏆 Best Practices

1. **Pre-Game**
   - Add all players
   - Test one substitution
   - Start timer with kickoff

2. **During Game**
   - Watch for red timer
   - Substitute at natural breaks
   - Use pause for timeouts

3. **Post-Game**
   - Check history for fairness
   - Note any major discrepancies
   - Clear session for next game
